# 内置模板维护

本 Skill 已包含核准的科顺蓝色 PSD、字体、品牌素材和 `assets/kesun-blue-manifest.json`。普通使用者直接生成套图，不需要提供 PSD，也不执行模板拆解。

## 运行时原则

- 只读取 `assets/kesun-blue-manifest.json` 中已确认的图层路径和几何规则。
- Photoshop 是高保真渲染权威；不要用 PSD 解析器重建光效、渐变、阴影或智能对象。
- 固定设计层不得改动。每周只替换主标题、人物、人物信息、时间、扫码文案、二维码和明确声明的可选素材。
- 如果图层缺失或命名不匹配，停止渲染并报告模板版本错误，不得自动猜测相似图层。

## 仅维护者升级模板时

只有在发布新的核准 PSD 版本时，维护者才需要重新检查图层：

1. 在隔离副本中检查 PSD 图层树、效果、智能对象和文本属性。
2. 更新内置 PSD 与 `assets/kesun-blue-manifest.json`，不要覆盖旧版本后继续沿用旧坐标。
3. 用单人、双人、三人及长短标题样例执行全套渲染。
4. 检查 PNG 尺寸、透明通道、人物安全区、标签碰撞和 PPT 页面尺寸。
5. 通过视觉复核后再发布新的 Skill 版本。
